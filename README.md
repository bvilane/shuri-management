# Shuri Safari Lodge Management

A modern, minimalist website for a safari lodge management company.

## Design Style

- Clean, minimalist design style
- Spacious layout with lots of white or light neutral background
- Natural textures (woodgrain, canvas, dust, sunlight beams) subtly in backgrounds
- Safari/lodge imagery with people as much as possible
- Subtle animations and movement:
  - Scroll-triggered animations (fade in, slide up)
  - Hover effects on cards, buttons, and service tiles
  - Soft image zooms or parallax on hero banners and lodge photos

## Typography

- Bold serif font for headings (Playfair Display)
- Clean, modern sans-serif for body text (Inter)
- Plenty of breathing room between text sections

## Project Structure

- `/src/app`: Main application pages
- `/src/components`: Reusable components
  - `/layout`: Layout components (Header, Footer)
  - `/sections`: Page sections (Hero, Services, etc.)
  - `/ui`: UI components (Button, Card, etc.)
- `/public/images`: Static images and assets

## Technology Stack

- Next.js 15
- TypeScript
- Tailwind CSS v4

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
